- **Order is file position.** Entries are appended at the end; existing lines are never edited or removed. The ISO 8601 timestamp records when the entry was written, so timestamps are **not** monotonic across the file.
- **A `DONE` that closes a task cites it** as `Ref \`<timestamp>\``. Work that had no originating task ends in `(standalone)` instead of a fabricated Ref.

`node scripts/todo_status.mjs` folds this file into the current open list; run it instead of reading the whole log.
