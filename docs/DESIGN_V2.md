## 0. 说明

### 0.1 目标

在 1.75C 的能力内按"正经赛车表"做：数据定义明确、来源可追溯、精度可验收、过期数据绝不冒充实时。

### 0.2 关键决策

| # | 决策 |
|---|---|
| D1 | 倾角 = 陀螺积分重力向量 + 运动学/静止/回零观测，废弃加速度计夹角 |
| D2 | 装车校准 = 旋转基 `R_mount`（forward/up），取代标量 `lean_zero_offset_cdeg` |
| D3 | 零偏只在静止学习 |
| D4 | QMI8658 FIFO（水位 4、Stream/128、448.4 Hz），失败自动回退轮询且**可见** |
| D5 | G 值在水平系表达 |
| D6 | 速度/航向设备端融合（下一阶段） |
| D7 | 速度页 = 速度·G 页 |
| D8 | 罗盘如实表达无磁力计：GNSS / HOLD / NO HDG |
| D9 | ROAD / TRACK 两种模式；TRACK 的圈速页推迟到外接 GNSS |
| D10 | 设备为计时与姿态的唯一记录源 |
| D11 | 新增 BLE 遥测服务；旧 snapshot 不变 |
| D12 | 行驶中以把手按键为主输入，触摸仅翻页 |

### 0.3 术语与帧

- 车架倾角 φ：车架相对重力竖直的横滚角，**右倾为正**。
- 有效倾角 φv：`atan(-v·ψ̇/g)`；挂身指数 = φv − φ。
- 帧：车体系 ISO 8855，**x 前、y 左、z 上**。画布 466×466，圆心 (233,233)，本文位置为相对圆心的**画布 px**（`d` 表示 360 设计 px）。
- 显示 G：lon 加速为正（球向上），lat 右转向心为正（球向右）。
- 航向：0° 正北，顺时针；旁航率 ψ̇ 左转为正。

### 1.3 硬件约束推出的规则

无磁力计 → 罗盘必须显示来源与保持；无光敏 → 亮度曲线 + 手动；触摸戴手套不可靠 → 行驶中按键；AMOLED 烧屏 → 轨道偏移 + 静止降亮；共享 I2C → FIFO 批量读、触摸中断读；发动机振动 → 448 Hz + LPF + 4 帧平均；整屏推屏开销大 → 分块失效、倾角页 30 fps 上限。

### 1.4 安装

优先装不随转向转动的部位。车把安装时转向角经转向轴倾角（约 25°）耦合为横滚/偏航，**校准必须龙头回正**，接受约 1° 误差。屏幕允许后仰，由 `R_mount` 吸收。减振支架的摇摆共振纳入 H2。杠杆臂 h = 设备安装点到横滚轴的垂直距离，进车辆档案。

## 2. 设计原则与骨架

### 2.1 原则

一页一个问题；形状先于数字；过期即消失；来源可见；峰值可追溯；不靠颜色单独表意。

### 2.2 模式与页序

| 模式 | 页序 | 进入 |
|---|---|---|
| ROAD | 导航 → 速度·G → 倾角 → 罗盘 → 音乐 → 0–100 | 默认 |
| TRACK | 圈速 → 速度·G → 倾角 → 0–100（**圈速推迟**） | 速度·G 页长按 B 3 s |

GTA 主题现行页序：导航 → 速度·G → 0–100 → 倾角 → 罗盘 → 音乐（6 页）。原先的纯速度页与罗盘页重复，已删除；`MOTO_UI_PAGE_SPEED` 现在就是速度·G 页。与 §7 的差异（按骑手要求）：G 摩擦圆是主角，圆心 `(0,+3)`、r=128 = 1.5 g（≈85 px/g），0.5/1.0 g 环 + 十字，G 球 18 px HUD 橙、尾迹 6 点 × 250 ms = 1.5 s，16 扇区包络（0.2 s 均值，HUD 金，未到达的方向留空不画尖刺），顶部实时合成 G（40 px），速度放进底部计数 slab；包络在任何页面都累积，在本页长按 2 s 清零。原版主题不变。

页码点沿 casing 弧 **r=203**，5 px，当前 16 px 品红，5 s 隐藏；TRACK 用方形点。

### 2.3 骨架

| 层 | 半径 | Day | Night |
|---|---|---|---|
| bezel | 222–233 | #07050D | #07050D |
| band | 212–222 | #F34DAA | #F34DAA |
| casing | 197–212 | #17151B | #0A0614 |
| 纸盘 | r=207 | #F6F0D7 | #141024 |

字体：`hero` 176、`timer` 96、`sub` 40、`plate` 24；band 刻度次 212→218/2 px、主 212→223/3 px、基准条 198→223/5 px。

### 2.4 告警与状态槽

- **每页一个状态槽**，坐标 `(0, +130)` 画布 px（倾角页已实现）；P0/P1 告警与页内状态**二选一**，告警优先。
- P2 提示另走顶部 `(0, −150)`，3 s 收起。
- 层级：覆盖层 > 告警 > 页内状态 > 内容。
- 每页在 gate 中声明槽位被占用时隐藏哪些元素（倾角页：状态 plate 压在地平线下方，不遮 hero）。

### 2.5 输入

| 输入 | 短按 | 长按 2 s | 长按 3 s |
|---|---|---|---|
| A | 下一页 | 上一页 | — |
| B | 确认告警 | 页内主功能（倾角页=清峰值） | 校准（仅倾角页） |
| BOOT | 下一页 | — | — |
| PWR | 息屏/亮屏 | — | — |
| 触摸滑动 | 翻页 | — | — |
| 触摸长按 | — | 同 B 2 s | 同 B 3 s |

**松手执行**：按住计时，2–3 s 松手清峰值；按满 3 s 松手进入校准（先 3 s 倒计时再采集）。进度环**延迟 300 ms** 出现，按 3 s 计。行驶 >10 km/h 时长按只能用按键。

### 2.6 亮度、时间与烧屏

有 RTC 时用 RTC；**无 RTC 时**开机时间未知，亮度只走手动，日志用单调时钟 + 会话相对时间，直到手机 TIME_SYNC。日夜在民用晨昏蒙影（−6°）切换，10 min 滞回。温度 >70/80 °C 降亮并提示。烧屏：120 s 轨道偏移 ±2 px；静止 5 min 降亮 30%，15 min 息屏（导航中除外）；VBUS 消失 60 s 降亮、10 min 深睡。

### 2.7 数字规则

速度 5 Hz/1 km/h/0.5 滞回；倾角 10 Hz/1°/0.6；方位 5 Hz/1°/0.6；秒表 20 Hz/0.01 s；G 峰值事件触发。图形按帧率，数字按表限频。

### 2.8 TTL

IMU 100 ms（失效进 NO IMU）；手机速度 2.5 s（过期改 IMU 外推，5 s 显示 `--`）；GPS 航迹 2.5 s（罗盘 HOLD）；路线 10 s 无心跳 ROUTE CACHED；音乐元数据 30 s。

## 3. 数据层

### 3.1 链路

```text
QMI8658 FIFO(水位4) → imu_task（4 帧平均 ≈112 Hz，时间戳重建，丢样/溢出计数）
  → LeanEstimator（φ, φ̇, θ, φv, ψ̇）
  → dyn_snapshot → UI / tlog / BLE
```

回退到轮询时：串口原因、会话元数据 mode=0、`kLeanImuFallback` 位、倾角页 `IMU POLL`。

### 3.2 IMU 采集

生产链路是**锁存轮询**（latch）。FIFO 窗口只留作 A/B 对照，见附录 D。

| 参数 | 值 |
|---|---|
| 加计 | ±8 g，ODR 448.4 Hz（code 0100，6DOF） |
| 陀螺 | ±512 dps，同 ODR（必须同频） |
| 寄存器 | CTRL1=0x40（地址自增 + 小端）、CTRL2=0x24、CTRL3=0x54、CTRL5=0x55（两路 LPF，约 5.39% ODR）、CTRL7=0x83、CTRL8=0x80 |
| AHB | CTRL9 命令 0x12 关闭 AHB 时钟门控。**这一步失败时不会报错，只会落到回退**：先看开机日志 `latch ready:` 一行和 `CTRL7=0x83`，再信任后面的数字 |
| 读取 | 定时器每 4464 µs（两个 ODR 周期）读一次锁存的最新样本，两次相邻样本取平均 |
| 预热 | 使能后 200 ms 丢弃样本（`after warmup:` 一行） |
| 计数 | `imu stats`：`samples`、`cycles`、`avail0`（读到时没有新样本）、`lockwait` / `lockto`（I²C 锁等待 / 超时）、`i2c`、`missed`、`flash` / `flashgaps`（超时的间隔里有多少被 flash 写解释）、`dt_max_us` / `dt_avg_us` |
| 开关 | NVS `imu.fifo`，**默认关**（即锁存）；串口 `imu fifo on|off` 只为 A/B |

**验收**（静置 10 分钟，每 60 s 一次 `imu stats`）：`avail0` 接近 0；`missed` 为 0，每个超时间隔都能被 `flashgaps` 解释；`lockto`、`i2c` 为 0；flash 写之外 `dt_max_us` < 8928（两个周期）；`samples` 约每秒 224 个。

### 3.3 安装校准

**步骤 1（熄火、静止）**：2 s 窗口，逐样本 `||a|−上一帧| < 0.01 g`，**陀螺标准差 < 0.5 °/s**（均值只做合理性检查，上限 15 °/s；原始值受 ±10 dps 初始偏置影响）。模长：0.85–1.15 g 合理，学习窗口均值为本机静止模长；每次成功都重学。`lean_trim` ±5°。

**步骤 2**：只修偏航，±10°，两段 0.5 s 一致才写入；否则拒绝。

**持久化** `att.rmount`：19 B，v2（trim cdeg、6×int16 1e-4、模长 0.01 m/s²、CRC16）；v1 直接拒绝并要求重校。NVS 偏移不变，换分区表不丢。

**移位监测**：10 次直线倾角中位数 >1.5° → P2 建议重校。

### 3.4 零偏

静止（有速度 <1 km/h；无速度另需抖动 EMA <0.004 g、模长匹配、持续 3 s），角速率门限 3 °/s 用**补偿后**的值，τ=10 s；行驶冻结；熄火写 NVS。

### 3.5 倾角估算器

状态 = 车体系中的世界竖直向量 û：

```text
û ← normalize(û − (ω × û)·dt)
φ = atan2(û_y, û_z)          右倾为正
θ = asin(û_x)                抬头为正（r1 修正符号）
ψ̇ = ω · û                    左转为正
```

杠杆臂：`a_y += h·φ̈`、`a_z += h·φ̇²`（陀螺横滚率 + 20 ms 滤波）。观测优先级：

| 条件 | φ_meas | τ | 附加门限 |
|---|---|---|---|
| v>4 m/s，age<1.5 s | `atan(−vψ̇/g) + atan2(a_y,a_z)` | 1.5 s | \|φ̇\|>30 dps ×0.3；\|φ̈\|>300 dps² ×0.3；颠簸 ×0.2 |
| 静止 | `atan2(a_y,a_z)` | 0.5 s | 同时混合整个 û（唯一俯仰观测） |
| 无速度直线 1.5 s | 0 | 3 s | \|ψ̇\|<1.5、\|φ̇\|<2、\|a_y\|<0.05 g |
| 其他 | — | — | 纯陀螺 |

定义：±70° 有效，超出 `SATURATED`；精度目标 静态 ≤0.5°、直线均值 ≤1°、稳态弯 ≤2°。俯仰仅静止可观测；GNSS 速度导数取俯仰待做（长 τ 回零兜底待做）。峰值：v>20 km/h、持续 0.3 s、quality≥60。

### 3.6 水平系 G

`g_lat = −v·ψ̇/g`（有速度）；否则 `(sinφ·a_z − cosφ·a_y)/g`；`g_lon = dv/dt`。4 Hz 显示低通，峰值用 0.2 s 均值。

### 3.7 速度融合

```text
x_h = normalize(x − (x·û)û)
a_lon = (a · x_h) − bias_lon
v += a_lon·dt; ZUPT 用 §3.4 判定
```

`bias_lon` 只吸收慢变（坡度、零偏）。GNSS fix 带时间戳回溯校正。

**实现**（`speed_fusion.cpp`，2026-10-26）：x_h 用倾角估算器上一样本的 û 求；停车判定沿用
§3.4 的静止门，持续 0.5 s 才做 ZUPT（v=0，此时剩下的水平纵向比力就是误差，`bias_lon`
以 τ=5 s 跟随）。轨迹每 50 ms 记一点，保留 3.2 s；fix 到达时与**fix 时刻**的轨迹比较，
残差乘标量卡尔曼增益（方差按 q 增长，测量噪声取 fix 自带的 speedAccuracy，缺省 0.5 m/s），
同一修正量加到 fix 时刻之后的全部轨迹和当前值上。第一个 fix 增益为 1。`bias_lon` 每个
fix 只按"残差/间隔"移动 5%（间隔 0.2–3 s 才算），限幅 ±2 m/s²。比已用 fix 更早或比轨迹
更老的 fix 拒收。输出给估算器的 age 是最新 fix 的年龄，5 s 后失效（§2.8）。

fix 时刻来自 BLE `GnssInput`（0x18，协议 §6.13）：手机在编码时打单调钟戳并附 fix 年龄，
设备取最近 16 条"到达 − 手机戳"的最小值作为时钟偏移。这是单向估计，看不见最短传输本身
（一两个连接间隔）；§12 的往返 TIME_SYNC 仍未做。不发 `GnssInput` 的旧手机仍走
NavigationSnapshot 速度，年龄从到达算起。

### 3.8 航向

GNSS 航迹校正；**静止冻结，不积分**。HOLD 只计"行驶中无 GNSS"的时长；σ≈残余零偏×行驶时长，>15° 或 15 min → NO HDG。

### 3.9 标志

`SRC_KIN/STATIC/ZERO`、`SPD_STALE`、`CAL_OK`、`IN_CORNER`、`CRASH`、`SATURATED`、`HDG_HOLD`、`GNSS_ONBOARD`、`IMU_FALLBACK`。

### 3.10 状态结构

`moto_ui_state_t` 扩展为 cdeg/cg 字段（见 §3.10 原表），`lean` clamp ±70 并置 `lean_saturated`。

## 5. 0–100

状态机：IDLE→ARMED→LAUNCH（g_lon>0.05 g）→DONE（插值到目标）→静止 1.5 s 重臂；ABORT（回落 >5 km/h、>30 s、|φ|>15°）。模式 0–100 / 0–60 / 100–0（B 长按 2 s）。精度 A/B/C，C 显示 `EST`。界面：chip `(0,−116)`、kicker `(0,−80)`、176 px 秒表 `(0,−14)`、12 段条 `(0,+72)`、BEST `(−52,+112)`、差值 `(+92,+112)`（40 px，进步实心/退步描边）、EST `(0,+150)`。BEST NVS 持久化，仅 A/B 级刷新。

## 6. 倾角页

人工地平线：盘固定、世界倾斜、太阳骑地平线、轮缘 blip。中心无符号数字（10 Hz、0.6° 滞回、<1.5° 显示 `0°`）、左右 `L/R` 40 px（±150,−8）、刻度 −60…+60 每 10°，峰值三角 + plate、最近三弯、个人极限斜纹。状态槽 `(0,+130)`：`CAL` 常驻（未校准时）、`CAL 3/2/1`、`CAL...`、`CAL OK`、`CAL FAIL MOVING/RANGE`、`IMU POLL`、`LOG FULL`、`LOG DIRTY`。长按 2 s 清峰值、3 s 校准；环 300 ms 后出现。

## 7. 速度·G

band 速度表（12 点顺时针，v_max 可配）+ 刻度、限速标记、超速斜纹闪、超量程端止条；176 px 速度 `(0,−52)`、单位 slab `(0,+22)`、限速牌 `(−108,−108)`（**候选，未过 gate**）、G 摩擦圆圆心 `(0,+118)` r=65（52 px/g，0.5/1.0 g 环 + 十字）、G 球 14 px、尾迹 1.5 s、16 扇区包络、峰值 plate `(±104,+76)`（已验算 r≈169）。

## 8. 罗盘

玫瑰 24 刻度随 −heading 转；固定 12 点索引；八方位 176 px；方位角 40 px；`HOME/DEST` slab 与时钟 slab；三态 GNSS/HOLD/NO HDG（刻度透明度递减，HOLD 显示 m:ss，静止不累计）。

## 9. 圈速（推迟）

**整章推迟**，等外接 GNSS。1 Hz 源只到 REF 级，不刷 BEST、不显示预测差值。

## 10. 音乐与覆盖层

音乐沿用；band 显示曲目进度；B 短按播放/暂停、长按 2 s 下一首；元数据 30 s 过期 `--`。覆盖层：DOWN/IMU FAULT（P0）、来电/电量/熄火/校准提示（P2）、存储只报 flash `LOG FULL`（**无 SD 告警**）。

## 11. 会话与存储

会话：首次 >10 km/h、TRACK 进入、静止 10 min、VBUS 消失 60 s。存储只用内部 flash。

**分区（32 MB）**：nvs 0x9000/0x6000（24 KB，**保持**，`att.rmount` 存活）、otadata 0xf000/8 KB、phy_init 0x11000/4 KB、app0 0x20000/6 MB、app1 0x620000/6 MB、assets 0xc20000/3 MB、coredump 0xf20000/64 KB、tlog 0x1000000/16 MB。换表必须 USB 全片烧写；CI 门槛 6 MiB×90%。

**tlog 自描述**：4 KB 块（magic MTLG、版本、块序号、boot id、首样本序号、payload_len、CRC32）。块先写 payload、最后写头；崩溃最多丢一块，读时跳过坏块。每 boot 首块带 SessionMeta（固件 hash、模式/ODR、h、估算器 τ/门限、MountRecord）。**不使用 NVS 记追加位置**：开机二分查找第一个全 0xFF 扇区。写满即停，倾角页显示 `LOG FULL`。运行时不再擦除扇区（擦除会关缓存几十毫秒、卡住 IMU 总线）：一次中断的写会留下 `LOG DIRTY`，录制保持关闭，直到主机擦除分区（台架计划 §5）。导出 `parttool.py read_partition --name tlog` → `moto_replay`（跳过 0xFF 扇区、逐块 CRC、按会话输出）。

## 12. BLE

旧 snapshot 不变；新增 dyn_stream（25 Hz）、event（弯道/峰值/计时/校准）、ctrl、backfill、gnss_in。**TIME_SYNC 往返式**：手机 t0/t3、设备 t1/t2，取最小 RTT；Android `elapsedRealtimeNanos`，iOS `fix_mono = mono_now − (wall_now − fix.timestamp)`，**不混用墙钟**。

## 13. 渲染与功耗

整帧 11–22 ms，但 CPU 软件绘制可能更贵；**倾角页 P1 门槛 ≥27 fps**，不达标先优化绘制。分块刷新跨 TE 仍会撕裂；无撕裂需 PSRAM 整帧 + TE 一次推完（备选）。任务：imu/estimator/lvgl core1，nimble/logger core0。亮度与静止降亮见 §2.6。

## 14. 测试与验收

### 14.1 单元

倾角静态/协调弯/挂身/无速度/偏航冻结/R_mount/水平 G/dt 无关；速度融合延迟；航向三态；0–100 t0；峰值规则；BLE codec；tlog 编解码与回放逐位一致。

### 14.2 几何 gate（常驻）

1. 有可见绘制（bg/边框/阴影）按对象框，框角 r≤195；圆角可按轮廓。
2. 透明容器与文字按**墨迹**（`lv_txt_get_size` + halo），测最坏字符串。
3. 越界标签必须 CLIP/DOT。
4. 白名单：不可见触摸层、整圆裁切图层、band/casing/bezel。
5. 同页墨迹两两不相交（告警/状态槽二选一）。
6. plate 内文字放得进 plate。

最坏字符串：`ACQUIRING GPS`、`888`、`88.88`、`+8.88`、`BEST 88.88`、`BRK 8.88`、`LAT 8.88`、`L 70`、`HOME 888`、`88:88`、`8:88.8`、`LAP 88`、`CAL FAIL`、`HOLD 88:88`、`POWER OFF 60`、`RECAL LEAN`、`NW`。

### 14.3 上板

见 `docs/BENCH_TEST_PLAN.md`（按顺序、关键字、通过标准）。

### 14.4 性能

各页 ≥目标 90%；FIFO 无溢出；I2C 最长阻塞 <8 ms。
