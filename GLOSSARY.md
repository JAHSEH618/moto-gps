# MOTO GPS Riding Instrument

Terms for the round-screen riding instrument, the phone-side ride recorder, and the telemetry that connects them.

## Language

**Radar**:
The full-screen, heading-up circular map view rendered on the round display.
_Avoid_: Minimap, 小地图, map page

**Home**:
The rider's saved home location and the one-tap action that routes to it.
_Avoid_: Home screen, 主页, safehouse

**Settings**:
The on-device configuration surface reached from the Radar.
_Avoid_: Preferences, config menu, 设置页

**Attitude Sample**:
One timestamped measurement of the bike's roll, pitch, longitudinal G, and lateral G from the bike-mounted inertial sensor.
_Avoid_: IMU frame, telemetry packet, sensor reading

**Lean**:
The bike's signed roll angle relative to gravity, positive when leaning right and negative when leaning left.
_Avoid_: 倾角, tilt, bank angle

**Ride**:
A navigation session, from navigation start to arrival or manual end, recorded automatically on the phone.
_Avoid_: Trip, 行程, session

**Performance Run**:
A single acceleration attempt from standstill to a target speed, recorded independently of a Ride.
_Avoid_: 0-100 run, drag run, acceleration test
