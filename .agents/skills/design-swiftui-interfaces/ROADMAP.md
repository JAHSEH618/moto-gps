# Roadmap

The roadmap is intentionally small: reliability and evidence come before additional visual effects.

## Next

- Add more static checks for platform-specific navigation and scene/window adaptation.
- Add sanitized fixture snippets for interrupted gestures, async cancellation, and reduced-effects fallbacks.
- Publish a tagged release with a reproducible source archive and checksum.

## Later

- Expand the Apple Fidelity review examples for visionOS, watchOS, and tvOS.
- Add optional visual regression guidance that does not require committing private screenshots or simulator data.

Suggestions are welcome in [Discussions](https://github.com/ZHUOLIN0928/swiftui-interface-design-skill/discussions).
