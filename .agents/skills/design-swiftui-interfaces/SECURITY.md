# Security policy

## Supported versions

Security fixes are applied to the latest version on the default branch and the latest tagged release.

## Reporting a vulnerability

Please use GitHub's private security advisory workflow for this repository. Do not open a public issue, attach credentials, or include personal data in a report.

Include the affected file or behavior, a minimal reproduction, impact, and a suggested mitigation when safe to share. If a credential was exposed, revoke or rotate it immediately; deleting a file does not revoke a credential.

This project is a local design and static-review Skill. It does not collect telemetry or require network access at runtime.
