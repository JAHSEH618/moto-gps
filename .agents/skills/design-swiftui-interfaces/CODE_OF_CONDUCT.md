# Code of Conduct

We are committed to a welcoming, respectful, and accessible project community.

Participants must avoid harassment, discrimination, personal attacks, doxxing, sexualized conduct, and publishing private information. Give actionable feedback about the work, assume good faith, and make room for different access needs and technical backgrounds.

Project maintainers may remove comments, close contributions, or restrict participation when behavior violates this policy. Report safety or conduct concerns privately through the repository's GitHub contact or security channel; do not publish sensitive details in an issue.
